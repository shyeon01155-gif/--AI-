# 반도체 실적 비교

삼성전자와 SK하이닉스의 OpenDART 연간 재무 실적(매출액, 매출원가, 판매비와관리비, 영업이익)을 비교하는 로컬 웹사이트입니다. 연결 기준 사업보고서 데이터를 조회합니다.

## 실행

1. Node.js 18 이상이 설치되어 있는지 확인합니다.
2. 프로젝트 폴더의 `.env.txt`에 `OPENDART_API_KEY=발급받은_40자리_키`를 설정합니다. API 키는 브라우저로 전송되지 않습니다.
3. 폴더에서 `node server.mjs`를 실행합니다.
4. 브라우저에서 `http://127.0.0.1:8000`을 엽니다.

사이트는 OpenDART `fnlttSinglAcntAll.json` 전체 재무제표 API를 사용해 두 회사의 연결 손익계산서에서 사업보고서(보고서 코드 `11011`) 연간 데이터를 읽습니다. 조회 결과는 6시간 캐시되고 회사별 계정 코드 차이를 반영합니다.

## 공개 배포 (Render)

프로젝트에는 Render Blueprint 설정(`render.yaml`)이 포함되어 있습니다. Git 저장소에 프로젝트를 올린 뒤 Render에서 **New > Blueprint**로 저장소를 연결하면 웹 서비스를 만들 수 있습니다. 생성 과정에서 `OPENDART_API_KEY` 항목에 OpenDART 인증키를 직접 입력하세요. 비밀키를 저장소나 코드에 적지 마세요. 배포가 완료되면 Render가 `https://<서비스이름>.onrender.com` 주소를 발급합니다.

무료 웹 서비스는 일정 시간 요청이 없으면 잠들 수 있어, 첫 접속 시 시작을 기다려야 할 수 있습니다.
